# Especificación de producto consolidada

La implementación autoritativa está formada por `data/scenario.yaml`, `docs/DATA_CONTRACT.md` y los
tests. Este documento conserva el objetivo de producto sin duplicar parámetros numéricos.

La aplicación debe ofrecer dashboard, ranking comparativo, bombos/sorteo, camino de Argentina,
cinco llaves visuales, fuentes/calidad, método Sirius, backtesting e historial de versiones.

El botón de actualización debe capturar cambios con trazabilidad y nunca reemplazar un snapshot
válido por un error. Toda salida debe distinguir hechos, supuestos y proyecciones. La astrología debe
mostrarse como experimento no validado científicamente y compararse siempre con el baseline.
