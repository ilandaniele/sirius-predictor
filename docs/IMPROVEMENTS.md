# Próximas mejoras objetivas

1. Sustituir ratings proyectados por snapshots Elo/FIFA con licencia y fecha de corte verificadas.
2. Incorporar zonas y sedes históricas exactas para los partidos cuyo archivo sólo publica hora
   local; hasta entonces esos kickoffs permanecen nulos para las técnicas horarias.
3. Congelar predicciones públicas de Sirius previas al evento, incluidos errores.
4. Añadir ablaciones por ciclo DT, debut, retorno solar/lunar, demi, cuartilunar y carta del partido.
5. Marginalizar horas natales desconocidas; nunca imputar 12:00 como hora real.
6. Contrastar el sampler con enumeraciones de torneos pequeños y diagnósticos de mezcla MCMC.
7. Implementar fair play y el reglamento oficial de desempate cuando exista para 2030.
8. Reemplazar participantes, bombos y llave hipotéticos cuando FIFA publique decisiones oficiales.
9. Añadir calibración isotónica o Platt sólo con validación temporal anidada.
10. Preregistrar Sirius Engine vN antes de cada torneo y conservar todas las versiones.
